# M0 界面提案 01

日期：2026-10-24。本文件保留首次 M0 提案的历史状态；原生工程现已建立，当前进度见[项目总览](../README.md)。下面描述仅适用于早期 HTML 原型。

打开 `index.html` 查看可交互的横屏 / 竖屏视觉原型。所有文档、来源和设备信息均为演示数据，无外部依赖、无网络请求。

## 设计取舍

- 横屏：280px 文件树 + 居中正文；竖屏：正文优先，目录以遮罩抽屉呈现。
- 原始文件名、目录独立展开、当前文件高亮；示例包括本地和 GitHub 来源。
- 暖白与深灰两套阅读配色；正文默认 18px / 1.78 行高，列宽含边距 760px。
- 工具栏仅保留侧栏、文件名、文章目录、阅读外观；GitHub 文档显示刷新。
- 支持文件切换、会话内阅读位置、内部示例链接、代码复制、字号与列宽调整。

浏览器 px 仅用于视觉评审，不视为 iPad pt 或动态字体验收。原生版应采用系统图标、系统安全区和无障碍语义，替换本原型的 Unicode 占位图标。

## 边界与待确认

- 添加来源、刷新仅提示；未实现文件访问、认证、缓存、Markdown 解析与 WebKit 集成。
- 示例 HTML 不能证明 GFM 支持、渲染安全、性能或实机阅读体验。
- 待确认：整体视觉、横竖屏布局、目录密度与阅读排版。确认后进入 M1。
- M1 前仍需确定测试 iPad / 最低系统版本、个人安装或公开分发，以及三个真实测试样例。

## 文档审阅

已审阅知识库五份文档及根目录维护规范。沿用 SwiftUI + WebKit 首选方向，不改变纯阅读 MVP 范围。正式技术选型与性能结论保留至 M1 实测。
