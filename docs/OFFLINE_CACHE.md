# 离线缓存与代码高亮

## 当前实现

缓存核心位于ReaderCore，使用Foundation和CryptoKit，供iPad、iPhone、Mac共用；缓存仅在本机，不跨设备同步。

0.2.0（44）起Mac移除缓存设置入口和页面，继续自动缓存，沿用已有容量偏好（新安装默认128 MB），不清除现有缓存。iPhone/iPad保留“••• → 离线缓存”，删除用户指定的私有隔离/加密/本地文件/跨设备同步说明段；底层行为不变。移动页面显示实际用量，提供64/128/256 MB上限（默认128 MB）和清理入口。自动缓存成功读取过的GitHub正文、列举过的目录、加载过的相对位图，以及解析分支所需元数据；不下载整个仓库，不复制本地原文件。总记录数另限512项，超限淘汰旧内容，优先保留小型解析元数据。缓存可能因容量、清理或损坏失去，不是永久收藏或备份。

固定提交内容优先使用内存/磁盘缓存；分支等可变信息联网时发送ETag/Last-Modified条件请求，304复用旧响应。只有断网类错误、限流冷却或500/502/503/504会回退到已有快照，并显示“缓存阅读”；未读内容明确提示尚未缓存。401/普通403/404、重定向、证书错误或取消不使用旧响应冒充成功。不能据此保证服务端额度永远充足。

缓存原文和资源，在打开时重新安全渲染，不持久化运行中的网页。相对图片仍受原来源路径范围限制，正文和图片使用同一提交。

## 私有内容与清理

公共响应与每份令牌分开命名空间；身份目录/文件名为摘要，不存令牌。认证响应（包括目录和元数据）使用AES-GCM加密，密钥由高熵令牌和用途前缀派生，不落盘；令牌仍只保存在Keychain。目录标记排除备份，文件权限0600，iOS另启用完整文件保护。非缓存响应头不持久化，不保存Authorization头。

替换/清除授权或服务器401会停用旧会话并删除对应私有磁盘缓存，旧图片加载器及在途响应不能重新写回；磁盘删除失败显示错误，不声称清理成功。移除GitHub来源会清理该身份下对应仓库的缓存，同仓库其他来源可能需要重新联网缓存。

“清空离线缓存”清理磁盘及内存响应，保留当前页面、来源链接和授权；随后继续阅读可重新产生缓存。清理/缩容使用修订票据阻止较慢的旧请求写回。没有联网时无法即时获知服务端撤权，已有离线内容可继续解密，直到本机清除或联网确认失效；不是远程即时擦除机制。

## 代码块高亮

已有highlight.js 11.11.1常用语言集，本轮补充同版本官方MATLAB语法模块，完全离线加载到WebKit隔离内容世界。MATLAB代码围栏标注`matlab`；大小写由渲染器归一。支持高亮、代码复制与代码块横向滚动，不执行代码，也不增加`.m`文件阅读或MATLAB计算功能。

未知/未标注语言与超过20,000字符的代码块保留纯文本，不自动猜测。内置“阅读示例 → 技术文档 → MATLAB代码高亮.md”包含MATLAB、Python、Swift和未知语言例子。
