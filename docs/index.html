在 iPhone 上

文字、代码与目录，各得其所。

表格、任务列表、代码高亮与文章目录，在小屏幕上同样清晰。

功能

为阅读准备的一切，仅此而已。

来源

文件、文件夹与 GitHub。

单篇 Markdown、本地文件夹，或 GitHub 仓库、子目录与单篇文档。保留原有目录层级，常读内容一键置顶。

只读

原文件，原封不动。

不编辑、不移动、不删除原文件，也不执行文档中的代码。移除来源只是从阅读器里移除引用。

字号

12–26pt

浅色、深色或跟随系统，四套阅读配色。

界面语言

5 种语言

简体中文、繁體中文、English、日本語、한국어，随时切换。

价格

免费

没有内购、广告或账号，不收集任何数据。

iCloud 同步

在另一台设备上接着读。

来源、置顶与排序和阅读位置经你的私有 iCloud 在设备间同步；文档正文和令牌不会上传，可随时关闭。

iPhone 与 iPad

小组件、Spotlight 与快捷指令。

用“继续阅读”小组件回到原位置，在 Spotlight 中搜索读过的文章，或让 Siri 继续阅读。
