使用帮助

  • Mac更新前先退出iMDReader，替换后从“应用程序”启动。若Dock仍打开旧版，移除旧图标，再将“应用程序”中的iMDReader固定到Dock；无需重复下载或清空资料库。
  • 用“＋”添加Markdown文件、本地文件夹或GitHub链接。应用只读原文件。
  • 文件失去访问权限时重新选择原文件/目录。单文件授权不包含父目录；相对图片可能需要目录权限。
  • GitHub私有内容需你自己的细粒度只读令牌。先检查网络及授权；离线仅能读取已缓存内容。
  • 移除来源不会删除原文件。“•••”可管理 GitHub 授权和 iCloud 同步，移动端另可管理离线缓存（Mac 自动管理）；Aa 调整阅读外观和界面语言。
  • iCloud 同步需在各设备登录同一 Apple 账户。同步来源、置顶与排序和阅读位置，不同步文档正文、令牌和外观设置；iCloud 云盘以外的本地文件夹只留在本机，其他设备首次打开 iCloud 云盘文件夹需重新授权。

反馈请说明App版本、设备/系统、复现步骤，并只附去除私人信息的截图。不要发送密码、令牌或私人正文。公开问题也可提交至GitHub Issues。

Help

  • For Mac updates, quit iMDReader before replacing it, then open it from Applications. If the Dock opens an older copy, remove that Dock item and pin the copy in Applications again. There is no need to download it again or clear your library.
  • Use “+” to add a Markdown file, local folder, or GitHub link. Original files remain read-only.
  • Re-select the original file or folder if access is lost. Single-file authorization does not cover its parent; relative images may need folder access.
  • Private GitHub sources require your own fine-grained read-only token. Check connectivity and authorization; offline reading requires cached content.
  • Removing a source does not delete original files. “•••” manages GitHub authorization and iCloud sync, and on iPhone and iPad also the offline cache (managed automatically on Mac); Aa controls reading appearance and interface language.
  • iCloud sync requires the same Apple Account on each device. It syncs sources, pins and order, and reading positions, but not document text, tokens, or appearance settings. Local folders outside iCloud Drive stay on the device; other devices ask for access the first time they open an iCloud Drive folder.

For support, include the app version, device/OS, and reproduction steps. Redact screenshots. Never send passwords, tokens, or private document content. Non-private issues may also be reported via GitHub Issues.

当前版本：Mac 0.4.1（GitHub）；iPhone 与 iPad 在 App Store 为 0.4.0，0.4.1 即将推出。
