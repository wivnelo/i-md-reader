简体中文

iMDReader是一款只读Markdown阅读器。本政策说明应用和支持联系的数据处理；不代表第三方服务不收集信息。

设备上的资料

文档、来源引用、阅读位置、外观偏好和缓存保存在设备上。应用不向开发者上传文档，不编辑、移动或删除原文件。仅通过系统选择器取得你选择的文件或目录权限；应用不提供自有账号、广告、跨设备同步或开发者自建分析服务。

GitHub与外部链接

使用GitHub来源时，应用向GitHub发送读取请求，包括仓库路径及网络请求所需信息；GitHub会接收IP地址和请求元数据。访问私有内容时，你提供的令牌保存在本机Keychain，只发送给GitHub验证。GitHub按其隐私声明处理这些数据。打开外部链接后，由浏览器和目标服务处理请求。本应用不将这些信息用于跨应用广告跟踪。

保存、清理与撤销

本机偏好和来源引用保留至你移除或重置应用资料；缓存按容量限制淘汰，也可在移动端设置清空。移除来源不删除原文件。清除GitHub授权会移除本机令牌及相关私有缓存；若需使令牌在GitHub端失效，请同时在GitHub撤销。离线时无法立即获知远端权限变化。第三方服务的数据保留和删除遵循其政策。

联系与反馈

支持及隐私请求请联系ronvex@icloud.com。如果你主动发送邮件，维护者会收到邮箱地址、正文及附件，仅用于处理该请求；邮箱服务商也会处理邮件。请勿发送令牌、密码、私人文档或不必要的个人信息。反馈只保留至处理问题及必要后续联系所需期间；可通过同一邮箱请求删除，依法必须保留的部分除外。公开GitHub Issues可被所有人看到，请勿在其中发送私人资料。

English

iMDReader is a read-only Markdown reader. This policy covers the app and support correspondence; it does not claim that third-party services collect no information.

Data on your device

Documents, source references, reading positions, preferences, and caches remain on your device. The app does not upload documents to the developer or edit, move, or delete original files. Access is limited to files or folders you select through the system picker. There is no app account, advertising, cross-device sync, or developer-operated analytics service.

GitHub and external links

GitHub reading sends requests containing repository paths and necessary network information to GitHub, which receives your IP address and request metadata. Optional private-access tokens are stored in the device Keychain and sent only to GitHub for authentication. GitHub processes information under its privacy statement. External links open in your browser, where the destination service handles the request. The app does not use this information for cross-app advertising tracking.

Retention, deletion, and revocation

Local preferences and references remain until you remove them or reset app data. Caches are bounded and evicted as needed; mobile settings also allow cache clearing. Removing a source does not delete its original files. Clearing GitHub authorization removes the local token and related private caches; revoke the token on GitHub separately to invalidate it there. Offline access cannot immediately detect remote permission changes. Third-party retention and deletion follow each service’s policy.

Support and privacy requests

Contact ronvex@icloud.com. If you send email, the maintainer receives your address, message, and any attachments solely to handle your request; the email provider also processes that correspondence. Do not send tokens, passwords, private documents, or unnecessary personal information. Feedback is retained only for handling the issue and necessary follow-up. You may request deletion through the same address, except where retention is legally required. GitHub Issues are public: never post private data there.

Changes to this policy will be reflected on this page and in its effective date.
