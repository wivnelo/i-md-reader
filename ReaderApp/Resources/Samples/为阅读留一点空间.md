# 为阅读留一点空间

让内容慢下来，让注意力回到文字本身。

打开一篇文档，应该像翻开一本书。目录帮你找到方向，排版让你愿意停留；当阅读开始，界面便安静地退到一旁。

> 好的阅读体验，不在于同时看见多少信息，而在于此刻能够专注多少。

## 文字的节奏

中文需要舒展的行距，英文需要自然的词间留白。标题、段落与引用各有自己的呼吸。Markdown brings structure to plain text，而排版让结构变得自然。

正文保持适当的宽度。无论横屏还是竖屏，视线都可以轻松找到下一行的起点。偶尔出现的 `inline code`，也应该融入文字的节奏。

## 清晰，但不喧闹

文件夹保留原来的层级，文章保留原来的名字。只需要展开、选择，然后继续阅读。

| 内容 | 呈现方式 | 阅读目的 |
| --- | --- | --- |
| 文件树 | 舒展的行距、柔和高亮 | 快速找到方向 |
| 正文 | 受控列宽、自然留白 | 专注长时间阅读 |
| 代码与表格 | 独立横向滚动 | 保留完整结构 |

## 代码也是内容

```swift
struct ReadingPreferences {
    var fontSize: Double = 17
    var lineHeight: Double = 1.65
    // 为文字留出呼吸的空间
}
```

代码保留缩进，支持复制。已识别的语言在接近阅读区域时着色；未知语言或过长代码块保持原文展示。

## 开始自己的阅读

通过左侧加号添加本地文件夹。本应用只读取其中的 Markdown 与相对图片，不修改你的文档。

- [x] 保留原始 Markdown 内容
- [ ] 花一点时间，验证长时间阅读的舒适度
