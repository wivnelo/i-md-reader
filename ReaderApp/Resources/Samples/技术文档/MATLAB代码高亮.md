# 代码高亮检查

代码块标注语言后进行语法高亮；不运行其中的代码。

## MATLAB

```matlab
% 绘制一个正弦波
x = linspace(0, 2*pi, 100);
y = sin(x);
for k = 1:3
    disp("Hello MATLAB");
end
plot(x, y);
```

## Python

```python
# A small example
for value in range(3):
    print("Hello", value)
```

## Swift

```swift
let title = "iMDReader"
for index in 0..<3 {
    print(title, index)
}
```
